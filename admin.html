PORTFOLIO MANAGEMENT

作品管理

用 GitHub 账号安全登录，即可发布或移除作品；授权由后端保管，不用每次复制 token。

连接管理后台

首次使用时配置一次 Supabase 项目。下面的 Project URL 和 anon key 是公开配置，不是 GitHub 密钥；GitHub 授权令牌只保存在后端。

这两项会保存在当前设备上；不要把 service_role key 或 GitHub Client Secret 填在这里。

首次设置 Supabase（一次性）
  1. 创建一个免费的 Supabase 项目，并运行仓库中的 supabase/migrations/20261012000000_create_manager_sessions.sql。
  2. 在 GitHub 创建 OAuth App，授权范围仅需公开仓库的 public_repo；回调地址使用 Supabase 函数 URL，详见 设置说明。
  3. 按设置说明部署 github-auth 和 github-manager 两个 Edge Functions，并在 Supabase 保存 GitHub OAuth 密钥。
  4. 从 Supabase 项目设置复制 Project URL 和 anon / publishable key，填入上方并保存。
